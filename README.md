# Cherry Ravewear Studio

**Primary passion brand** of Cyber Lazer Mermicorn.

> Creative direction for rave clothing. Designer owns concept, silhouette, color, materials, and storytelling. Production partners handle patternmaking, sewing, and construction.

## 1. What this project does
Turns Cherry’s ravewear ideas into production-ready, market-testable collections with AI-assisted mockups and clear hand-off packages for sewers.

## 2. Who it is for
Customers, sewing contractors, manufacturers, and creative employers evaluating the portfolio.

## 3. What exists today
Foundation structure, Drop 001 concept locked, shared Mermicorn contract in place.

## 4. What is planned
Three-look capsule, full visual asset pack, tech-pack drafts, product page copy, and social campaign assets.

## 5. What it does not claim
Cherry does not sew the garments. Production is partnered. No manufacturing capacity is claimed here.

## 6. First proof artifact
**Cyber Lazer Mermicorn — Drop 001**  
Theme: bioluminescent ocean × cyber fantasy × Honolulu nightlife  
1. Hero bodysuit or two-piece set  
2. Modular shrug / sleeves / hood  
3. Unisex accessory or utility piece  

Each design package will contain front/back/side concepts, three colorways, materials & trims, lighting effects, production difficulty rating, tech-pack draft, manufacturer questions, price tier, product page copy, and social assets.
