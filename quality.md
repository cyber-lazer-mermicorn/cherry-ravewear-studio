# Quality

## Delivery law
First pass is last pass. No placeholder looks. Production-useful packages only.

## Definition of Done — Design Package
- [ ] Validates against `schemas/design-package.schema.json`
- [ ] Concept statement ≥ 40 characters and specific
- [ ] Silhouette category + fit + key lines
- [ ] Three colorways with descriptions
- [ ] Materials notes usable by a sew partner
- [ ] Four views with prompt refs (front, side, back, detail)
- [ ] Production difficulty set
- [ ] ≥ 1 open manufacturer question
- [ ] Product copy short + long
- [ ] Uncertainty list present (empty only if truly nothing unknown)
- [ ] Rights block points to mermicorn-grove/LICENSE
- [ ] No claim that Cherry sews the garment

## Non-negotiables
- Unpublished masters stay private
- Visuals must be production-useful, not only aesthetic
- Public text stays honest about status
