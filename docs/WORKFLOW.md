# Ravewear Design Workflow

Operating loop for this studio:

```text
Discover → Compare → Verify → Design → Package → Sell → Learn
```

## Stages

### 1. Discover
- Mood, event type, movement needs, climate, light conditions
- Reference board (private or sanitized)
- Constraint list: budget band, sew difficulty, coverage, hardware availability

### 2. Compare
- Competing silhouettes and finishes in the same lane
- What is overdone vs still rare on the floor
- Material and reflective behavior under club / LED / daylight

### 3. Verify
- Feasibility with partner capacity (Cherry does not sew)
- Material availability
- Comfort and movement reality check
- Rights: original vs third-party risk

### 4. Design
- Concept statement
- Silhouette and key lines
- Palette + finish
- Materials and trims
- Three colorways minimum
- Multi-view AI mockup prompts (front, side, back, detail)

### 5. Package
Fill a complete design package (see `schemas/design-package.schema.json`):
- Construction notes
- Open manufacturer questions
- Product copy + social hooks
- Production difficulty rating
- Uncertainty list

### 6. Sell (when ready)
- Campaign assets via graphic-ai lane
- Listing package via commerce-ai lane
- Partner handoff packet only — no false in-house production claims

### 7. Learn
- What landed / what failed on the floor
- Partner feedback
- Update STATUS.md and collection notes

## Definition of Done — Design Package
See `quality.md`. A package is not done until every required schema field is honest and the uncertainty list is non-empty where knowledge is incomplete.
